# Cloud-Sentinel: Governance & Compliance Baseline

This project provides a "Governance-as-Code" framework designed to secure Azure and AWS 
environments for small businesses and nonprofits. It aligns cloud architecture with 
NIST 800-53 and CIS Benchmarks to ensure data integrity and global compliance.

## Current Modules
- [x] Identity Governance (Emergency Access / Break-Glass)
- [ ] Data Residency & Sovereign Cloud Mapping
- [ ] Cloud Incident Response Runbooks
